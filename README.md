# 🔍 OptiSense AI

### See Smarter. Detect Faster. 🚀

**OptiSense AI** is an intelligent, real-time computer vision application designed to detect, identify, and track multiple objects in images, videos, and live webcam streams. Built using Python, OpenCV, and YOLO, the system combines object detection, visual tracking, and interactive analytics in a user-friendly interface.

The project transforms visual data into meaningful insights by identifying objects, displaying their locations, calculating detection confidence, and presenting real-time performance statistics.

## ✨ Key Features

* 🎯 **Real-Time Object Detection:** Detect multiple objects using a pretrained YOLO model.
* 📸 **Image Analysis:** Upload images and identify objects with bounding boxes, labels, and confidence scores.
* 🎥 **Video Processing:** Analyze prerecorded videos and visualize detected objects frame by frame.
* 📹 **Live Webcam Detection:** Detect objects directly through a webcam.
* 🔄 **Object Tracking:** Track detected objects with optional tracking IDs.
* 📊 **Visual Analytics:** Display object counts, detection statistics, FPS, and inference time.
* 📁 **Export Results:** Save annotated images, processed videos, and detection reports in CSV format.
* 🖥️ **Interactive Dashboard:** Explore detection results through a Streamlit-based interface.
* ⚡ **Local Processing:** Run the application locally without requiring paid external APIs.

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Computer Vision:** OpenCV
* **Object Detection:** Ultralytics YOLO
* **Deep Learning:** PyTorch

* **User Interface:** Streamlit, Custom CSS
* **Data Visualization:** Plotly

* **Testing:** pytest

## ⚙️ How It Works

1. **Input:** Provide an image, video file, or live webcam stream.
2. **Preprocessing:** OpenCV processes the visual input into frames suitable for analysis.
3. **Detection:** The pretrained YOLO model identifies objects and predicts their locations and classes.
4. **Visualization:** Bounding boxes, object labels, and confidence scores are displayed.
5. **Tracking:** The optional tracking functionality assigns IDs to objects across video frames.
6. **Analytics:** The application calculates object counts and performance metrics.
7. **Export:** Save the processed media and detection results for further analysis.
